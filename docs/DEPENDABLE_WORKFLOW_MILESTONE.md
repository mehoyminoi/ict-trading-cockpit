# Dependable personal Study/TDA/Watch milestone

Accepted priority, 2026-10-30: deliver a dependable personal cockpit integrated into the operator's daily routine before allocating substantial effort to exploratory features. Preserve the accepted design language and friction improvements where they materially support correct work; operational UX is part of readiness, while optional decorative polish is not the release criterion.

## Completion means usable journeys

- Study: begin or resume an identifiable investigation, select a clear historical reference, capture examples/images/questions/findings, reflect at a natural pause, and recover the work after restart without reconstructing associations.
- TDA: follow the active plan through mapped chart/pane context and retain the resulting operating context without transcription or scope ambiguity.
- Watch: consult that context, update current AMDX, capture observations and return to the operational anchor efficiently; unknown/blocked/available states remain truthful.
- Recovery: preserve the actual database, images and settings; verify restore on a separate copy; migrations must preserve real records. Backup creation alone is not a tested recovery path.
- Integration: run complete representative journeys with meaningful material, then consolidate the tested draft-PR stack through separately authorized integration/merge work. Individual passing smoke checks do not establish a release.
