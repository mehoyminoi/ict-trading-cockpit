Reopening queries persisted material; selection inside the overview is not retained. Existing Study Find and evaluation controls remain the entry routes after returning; no automatic cross-item association is introduced.

The implementation deliberately reuses existing storage. A linked draft is not a saved find. A criterion match is not trading performance. Saved item inspection is not competency assessment.
